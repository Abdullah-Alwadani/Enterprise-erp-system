# Frontend

React TypeScript frontend for the Enterprise ERP System.

## Run Locally

```bash
npm install
cp .env.example .env
npm run dev
```

The frontend expects the backend API at:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```
