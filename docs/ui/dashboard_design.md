# Dashboard Design

## Purpose

The dashboard provides a management overview of ERP activity and operational health.

## KPI Cards

- Total employees
- Total products
- Low-stock products
- Total suppliers
- Pending purchase requests
- Monthly sales revenue
- Unpaid invoices
- Sales orders

## Charts

- Sales revenue by status
- Inventory stock by status
- Procurement totals by status
- Finance invoice/payment/outstanding totals

## Recent Activities

Recent audit log entries are shown as an activity feed so managers can quickly see important system changes.

## UI Style

- Sidebar-based ERP layout
- Compact cards and tables
- Clear status badges
- Responsive layout for desktop and tablet widths
- Neutral professional palette with focused accent colors
